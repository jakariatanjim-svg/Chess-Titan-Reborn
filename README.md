# Chess Titan Reborn

Chess Titan Reborn is a browser chess game that recreates the satisfying, tabletop feeling of classic desktop chess with a fresh presentation for the web.

## Availability

The game is currently in development and is not ready to play yet. A public web build will be linked here when it is available.

## What to expect

- Play a complete game of standard chess in your browser
- Challenge a built-in computer opponent
- Choose between two board looks: **Classic Matte** and **Reborn Glass**
- Enjoy a tactile 3D board, clear piece movement, and responsive controls
- Play without an account or a separate game service

## Browser requirements

Use a current version of Chrome, Edge, Firefox, Safari, or another modern browser with WebGL and WebAssembly enabled.

## Privacy

Chess Titan Reborn is designed to run in your browser. It does not require an account or a hosted game server. Any game preferences or saved game data will stay on your device.
